# Agenda de Contatos Web

## Integrantes

- Seu Nome
- Nome da dupla (se houver)

## Descrição

Aplicação web desenvolvida utilizando HTML5, CSS3 e JavaScript Vanilla para gerenciamento de contatos.

Os dados são armazenados no Google Firebase Firestore, permitindo cadastro, edição, exclusão e listagem dos contatos em tempo real.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Firebase Firestore

## Funcionalidades

- Cadastro de contatos
- Edição de contatos
- Exclusão de contatos
- Listagem em tempo real
- Banco de dados em nuvem
- Regras de segurança no Firestore

## Banco de Dados

Google Firebase Firestore

## Segurança

Foram implementadas regras de segurança no Firestore para validar os dados enviados antes da gravação no banco.

## Como executar

1. Abrir o projeto no VS Code
2. Instalar a extensão Live Server
3. Executar o arquivo index.html usando Live Server
